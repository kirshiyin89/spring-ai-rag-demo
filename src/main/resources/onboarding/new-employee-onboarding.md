# New Employee Onboarding

## Overview

Every new employee follows the company onboarding process before starting normal work.

The employee's manager starts the onboarding request with HR and IT before the employee's first working day.

## Before the First Day

HR creates the employee record and confirms the start date.

The manager provides IT with:

- employee name
- department
- job title
- manager
- start date
- required systems
- required hardware
- required software

IT prepares the employee's standard account and laptop.

The manager should request additional access separately when the standard access does not cover the employee's role.

## First Day

The employee receives:

1. Company laptop
2. Company account
3. SSO access
4. MFA setup instructions
5. Standard communication tools
6. Basic network access

The employee must complete MFA setup before accessing protected company systems.

## Hardware

The standard developer setup includes a company laptop, charger, external monitor, keyboard, mouse, and headset.

Hardware requests are handled through the IT Service Desk.

See `laptop-request.md` and `equipment-request.md`.

## Software

Employees receive the standard software package for their department.

Developers normally receive:

- approved IDE
- Git
- GitLab access
- VPN client
- company communication tools
- approved security tools

If an employee needs additional software, they must submit a software request.

See `software-license-request.md`.

## GitLab

Developers need GitLab access to work with source code and CI/CD pipelines.

The manager or team lead requests access for the employee.

See `gitlab-access.md`.

## Network Access

Employees working outside the company network need VPN access.

Office employees use the company WLAN.

See `vpn-and-wlan-access.md`.

## First Week

During the first week, the employee should:

- complete security training
- confirm laptop access
- configure MFA
- verify GitLab access
- verify required software
- verify network access
- meet the team
- review the team's development documentation

If a required service does not work, contact the IT Service Desk.

## Access Principle

Employees receive access based on their role.

Do not request access simply because another employee has it. The manager must justify additional access when required.
