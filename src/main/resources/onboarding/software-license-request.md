# Software License Request

## Overview

Employees can request software that they need for their work.

FinFlow provides a standard set of approved software. Additional software may require approval.

## Standard Developer Software

Developers normally receive access to:

- Git
- GitLab
- IntelliJ IDEA Community or approved JetBrains products
- Docker
- Kubernetes command-line tools
- company VPN client
- Microsoft Teams

The exact software depends on the employee's role.

## Paid Software

Paid software requires a software license request.

For example, a developer who needs **IntelliJ IDEA Ultimate** must submit a software request if the license is not already assigned to them.

The request should include:

- software name
- requested version, if relevant
- business reason
- employee name
- department
- manager

The manager approves the business need.

Procurement or IT handles license purchasing when required.

## Open Source Software

Employees may use approved open-source software for development.

Using an open-source library in a company product must follow the company's software security and licensing rules.

Developers must not introduce software with unclear licensing into production systems.

## Unapproved Software

Employees must not install unapproved software on company-managed devices when the software creates a security or licensing risk.

If you are unsure whether software is approved, contact the IT Service Desk before installing it.

## License Problems

Contact the IT Service Desk when:

- a valid license does not activate
- a license has expired unexpectedly
- the wrong license was assigned
- software installation fails

For a general software request, submit a software license request instead.

## Approval

A software request does not automatically grant access.

The request may require:

1. Manager approval
2. Security review
3. Procurement approval
4. IT installation or license assignment

The required approvals depend on the software.
