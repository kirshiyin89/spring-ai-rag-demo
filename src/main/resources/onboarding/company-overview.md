# FinFlow Technologies — Company Overview

## Who We Are

FinFlow Technologies is a fintech company that builds software for payment processing, financial data management, and internal banking platforms.

The company operates primarily from Budapest and works with customers and financial partners across Europe.

FinFlow has around 450 employees. The main teams are:

- Engineering
- Cloud & DevOps
- Architecture
- Quality Assurance
- Product Management
- Information Security
- IT Support
- Human Resources
- Finance
- Procurement

## Technology

The main engineering technology stack includes:

- Java
- Spring Boot
- Python
- PostgreSQL
- Apache Kafka
- Kubernetes
- Helm
- GitLab
- AWS

Engineering teams use GitLab for source control and CI/CD. Production workloads run on AWS and Kubernetes.

## Identity and Access

Employees use company SSO to access internal systems. MFA is required for company accounts and systems that contain sensitive information.

Access depends on the employee's role. New employees receive only the access required for their job.

Additional access requires an access request and appropriate approval.

See:

- `new-employee-onboarding.md`
- `gitlab-access.md`
- `vpn-and-wlan-access.md`

## IT Support

The IT Service Desk handles common employee technology problems, including:

- laptop problems
- monitor and headset issues
- software installation problems
- VPN problems
- WLAN problems
- account problems
- access problems

Employees should contact the IT Service Desk before contacting individual infrastructure or security engineers for normal support requests.
